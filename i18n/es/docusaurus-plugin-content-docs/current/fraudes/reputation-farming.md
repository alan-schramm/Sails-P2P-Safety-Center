# Manipulación de reputación y estafas de salida

**Situación:** Un participante construye un historial con operaciones pequeñas y luego propone una operación mucho mayor o inusual.

## Señales de alerta
- Muchas operaciones pequeñas seguidas de un aumento brusco.
- Historial concentrado en pocas contrapartes.
- Presión para evitar límites o cambiar instrucciones.

## Cómo actuar
1. Evalúa el riesgo de la operación actual, no solo la puntuación.
2. Respeta los límites y el proceso de liquidación aplicables.
3. Verifica condiciones extraordinarias y cambios de pago.
4. Detén la operación si el riesgo actual difiere del historial.

## Límites
La reputación no garantiza identidad ni honestidad futura. El análisis de redes Sybil, el decaimiento temporal y la diversidad de contrapartes figuran como planes, no protecciones universales.

**Estado:** orientación educativa general; no constituye una función automática implementada ni una garantía de recuperación.
