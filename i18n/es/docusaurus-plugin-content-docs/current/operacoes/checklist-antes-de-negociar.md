# Lista de seguridad antes de operar

Antes de aceptar una operación P2P, verifica la contraparte, el método de pago, las instrucciones y el importe. Conocer al operador o ver una puntuación alta no es suficiente.

## Lista operativa
1. Confirma activo, importe, red, precio, comisiones y plazo.
2. Comprueba beneficiario y datos bancarios en el flujo autorizado.
3. Considera historial y señales de confianza como indicadores, no garantías.
4. Verifica las reglas reales de escrow y disputas de la aplicación y red elegidas.
5. Utiliza canales autorizados; nunca compartas frases de recuperación ni códigos.

## Detente y verifica
Si cambia el destinatario, interviene un tercero o te presionan para salir de la plataforma, detente y verifica.

## Límites
Esta lista no demuestra titularidad bancaria, no impide reversiones ni garantiza la operación.

**Estado: orientación educativa general; no afirma una protección implementada.**
