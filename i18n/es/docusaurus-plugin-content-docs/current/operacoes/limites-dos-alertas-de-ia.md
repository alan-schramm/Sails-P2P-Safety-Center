# Cómo interpretar alertas de IA

**Situación:** una aplicación muestra una recomendación o alerta de IA durante una operación. Úsala para comprobar hechos, no como autorización de pago ni prueba de fraude.

## Qué significa una alerta

Una alerta puede señalar un patrón sospechoso y también puede equivocarse. La ausencia de alerta no demuestra seguridad: el recurso puede estar desactivado, no disponible o no reconocer el caso. Verifica datos, pago y canal independientemente de la recomendación.

## Cómo usar la recomendación

1. Comprueba qué información se analizó y qué afirma realmente la recomendación.
2. Verifica los hechos de forma independiente, mediante tu banco y las instrucciones autenticadas de la operación.
3. Revisa importes, destinatarios y condiciones de cada borrador antes de autorizar una acción.
4. Conserva las recomendaciones y el contexto relevantes para una disputa sin exponer datos personales innecesarios.

Nunca envíes contraseñas, claves privadas, frases de recuperación ni códigos de autenticación a una herramienta de IA.

## Contexto de Sails

La documentación consultada describe borradores y consejos revisados por el usuario; las alertas de ingeniería social dependen de activación por el operador. Eso no demuestra disponibilidad en la aplicación utilizada. Comprueba qué recursos están habilitados.

La inferencia en el node no significa necesariamente ejecución en tu teléfono u ordenador. Antes de enviar datos, verifica quién opera el servicio y sus políticas de acceso y retención. Las herramientas de lectura para IA de este portal tampoco verifican pagos ni deciden disputas.

## Límites

Una recomendación no sustituye las verificaciones ni garantiza resultados. Este artículo no anuncia agentes autónomos, detección de todos los fraudes ni liberación automática.

**Estado:** orientación educativa con contexto documental condicionado a la configuración; no certifica protecciones en cada implantación.
